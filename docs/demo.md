# 시연영상 구간 안내

[시연영상 보기](../media/demo.mp4)

장치 촬영 화면과 터미널 로그를 함께 보여주는 프로젝트 당시 영상입니다. 아래 시점은 해당 장면을 찾기 위한 대략적인 위치입니다.

| 영상 시점 | 볼 수 있는 장면 | 구조와 연결되는 부분 |
|---|---|---|
| 약 4초 | 초음파 접근 감지와 카메라 촬영 | 접근 이벤트→사진 한 장 캡처 |
| 약 15초 | 소유자 사례 | 소유자 판별 입력 사례 |
| 약 26초 | Owner는 저장하지 않는다는 안내 | SaveTask의 저장 생략 분기 |
| 약 36초 | Background는 저장하지 않는다는 안내 | 배경 필터와 저장 생략 |
| 약 47초 | Stranger 저장 안내 | 낯선 사람만 원본 사진 저장 |
| 약 58초 | Zybo 태스크 로그 | 수신→판별→저장 순서, 일부 구간 2배속 |
| 약 69초 | ISR→Binary Semaphore→RxTask 설명 | 인터럽트와 태스크 실행 조건 |
| 약 80초 | 처리 후 Idle 복귀 | 다음 접근 이벤트 대기 |
| 약 91초 | raw 저장과 파일 hex 표시 | 사진 저장 파일 확인 |

영상은 제시된 사례의 흐름을 확인하는 자료입니다. 정확도·처리시간·전력이나 최종 320×240 전송의 전체 byte 무결성을 정량 검증한 시험과 구분합니다. 지표의 조건은 [결과 문서](results.md)를 참고하세요.
