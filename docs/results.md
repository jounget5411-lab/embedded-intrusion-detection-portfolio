# 결과와 확인 조건

## 시연에서 확인한 동작

원보고서의 터미널 화면에는 접근 인터럽트→RxTask→AITask→SaveTask→Idle 복귀가 기록되어 있습니다. `OTHER` 판정의 저장 분기와 `OWNER` 판정의 저장 생략 분기가 제시됩니다. README의 영상과 함께 장치 동작 흐름을 확인할 수 있습니다.

보고서 화면에는 중간 버전의 64×64/8,192바이트 표기와 최종 부록의 320×240/153,600바이트 설정이 함께 남아 있습니다. 상태 전이 시연과 최종 설정의 전송 무결성 검증을 같은 결과로 묶지 않습니다.

## 모델 학습 결과

| 지표 | 보고서 값 | 조건 |
|---|---:|---|
| 데이터 수 | 360장 | 배경·소유자·낯선 사람 각 120장이라는 보고서 설명 |
| 학습 / validation | 300 / 60장 | 각 클래스 train 100·validation 20 설명 |
| 최고 validation accuracy | 93.33% | PC의 3클래스 softmax validation 결과 |
| 모델 입력 | 1×64×64 grayscale | 정규화 [-1,1] |
| 최종 장치 판별 | background 확률 + embedding cosine | threshold 0.60/0.85, 별도 정확도 수치는 확보되지 않음 |

보관된 학습 데이터 목록은 보고서의 클래스별 구성과 일치하지 않고, 보관 스크립트의 클래스별 20% 자동 분할도 보고서의 각 100/20 분할과 다릅니다. 따라서 동일 실험으로 확정하지 않았습니다. 이 저장소는 얼굴 이미지 dataset을 공개하지 않으며, 보관 체크포인트를 다시 학습하거나 장치 정확도를 재측정하지 않았습니다.

## 전력 분석의 범위

| 항목 | 값 | 종류 |
|---|---:|---|
| STM32 최대 감시 전력 | 0.165 W | 데이터시트의 3.3 V × 50 mA 조건 계산 |
| Zynq active | 1.548 W | 보고서의 Vivado 전력 추정 |
| Zynq idle | 0.152 W | 보고서의 Vivado 전력 추정 |

이 값은 실물 시스템 전류를 새로 측정한 결과가 아닙니다. 서로 다른 active budget을 나눈 배수를 장치의 실측 절감률이나 배터리 수명 개선으로 표현하지 않습니다. 구현으로 설명할 수 있는 것은 이벤트에 따른 촬영·처리·저장, 태스크 block과 Idle Hook WFI입니다.

## 현재 확인 상태

소스와 보고서의 구조를 대조하고 출처·버전 차이를 문서화했습니다. MCU/SDK 전체 빌드, GPIO 배선 재검증, 최종 용량의 SPI 무결성 시험, Owner template 재생성, 장시간 동작 시험은 이번 정리에서 수행하지 않았습니다. 이어서 재현할 항목은 [재현 안내](reproduction.md)에 있습니다.
